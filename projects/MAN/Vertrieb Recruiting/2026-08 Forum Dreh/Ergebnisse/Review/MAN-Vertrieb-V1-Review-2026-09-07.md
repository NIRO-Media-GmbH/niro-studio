lokal unter `Material/Videos V1/`. Geprüft gegen das Konzept (Google-Sheets-PDFs,

Ton-Löcher, Untertitel korrekt geschrieben (auch da, wo der ASR sich verhört —
„Lieblingsterrain"), CTA-Takes wie im Plan (V2 „Team der Löwen"-Nachdreh, kein

## 4. Grafik, Untertitel, Set — KANN

- **Untertitel als 2–3-Wort-Fragmente** („und ferngesteuerten", „habe,", „ein.", „auf das"). David-Regel 12.08.: immer ganze Sinneinheiten, nie Satzteile. Karaoke-Highlight kann bleiben, aber Blöcke auf Sinneinheiten setzen.
- **Keine Takeaway-Captions.** Der Plan sah je Video 3–5 Captions vor (V1 „Die Vicky verkauft LKWs" / „Business Case" / „Deine Chance" / „Sei mutig." · V2 „Trucks · Vans · Busse" / „Niemand muss überredet werden" / „Wir verkaufen Lösungen" · V3 „07:30 — To-do-Liste" / „Beziehung statt Quartalsdruck" / „Dein Tag. Dein Design." · V4 „Tag 1: Ausstattung. Tag 2: Praxis." / „2 Jahre. Theorie → Praxis." / „Der erste RoMAN"). Im Schnitt gibt es nur rote Wort-Highlights im Untertitel. David-Regeln MAN: Takeaways statt Voll-Zitate, nie >5 s ohne Grafik-Bewegung — die Talking-Head-Strecken (V4 0:50–0:57, V2 0:44–0:54) laufen nur mit Untertitel.
- **Endcard:** helles Grau, runder roter Pill-Button, kein Löwe. Die man.eu-Tokens (Memory „MAN Web-Design-Stil") sind Anthrazit, Radius 0, Rot nur als Akzent, Versalien, Löwe. Alle vier Endcards identisch — je Video Berufstitel setzen (V4 Trainee), „Truck · Van · Bus" nur, wo es passt (V2 Roman verkauft Transporter). Endcard-URLs/Wortlaut bei MAN weiter offen.
- **B-Roll-Wiederholung im Set:** High-Five-Sprung (V1 0:40, V4 0:44), Riesenschlüssel-Übergabe (V2 0:36, V3 0:34, V4 0:38), Laptop-Hände (alle vier), Halle-Walk-in (alle vier), Kaffeestation (V1, V4). Für ein Kampagnen-Set streuen — Inventar in `_intern/broll_inventar.csv`, 66 a7MK4-Clips auf dem NAS sind einsortiert.
- Inserts bitte auf dem Gesicht der Person starten (V1 0:30 Esther über Laptop, V3 0:12 Victoria über Roman).
- Länge: Wenn das Set bewusst als 45–60-s-Social-Format laufen soll, ist das eine Entscheidung — dann aber mit Konzept-Abgleich, welche Beats geopfert werden. Empfehlung: V1/V3/V4 auf 65–80 s mit den fehlenden Kern-Beats, V2 kann kurz bleiben.
